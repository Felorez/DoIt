# Делай. — список задач на Django

Небольшое учебное приложение для личных задач. Можно зарегистрироваться, войти, добавить, изменить и удалить задачу. Задачи каждого пользователя отображаются в его списке.

Это форк [Ayushsav/Todo_app_using_django](https://github.com/Ayushsav/Todo_app_using_django), созданного Ayush Savner. В этом форке обновлены страницы регистрации, входа, списка задач и редактирования: адаптивная компоновка, новые цвета и более ясные формы.

## Запуск на Windows

Нужен Python. Выполните в терминале:

```powershell
git clone https://github.com/Felorez/Todo_app_using_django.git
cd Todo_app_using_django/todo
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install "Django>=4.2,<5"
python manage.py migrate
python manage.py runserver
```

Откройте [регистрацию](http://127.0.0.1:8000/signup/) или [вход](http://127.0.0.1:8000/loginn/). Для панели `/admin/` отдельно создайте суперпользователя командой `python manage.py createsuperuser`.

Проверено локально с Python 3.12 и Django 4.2.30: проверка Django проходит, формы открываются, вход и добавление задачи работают.

## Возможности

- Регистрация и вход через систему пользователей Django.
- Добавление, редактирование и удаление задач.
- Список задач текущего пользователя.
- SQLite для локальных данных.

## Важно

Это учебный прототип для локального запуска. Перед размещением в интернете нужно убрать `DEBUG=True` и ключ из `settings.py`, прекратить вывод паролей в журнал и ограничить редактирование и удаление задач их владельцем.
